# שקשוקה סיטי (Shakshuka City)

אתר סטטי: עיר תלת-ממדית שבה כל תושב מקבל בית בצורת מחבת שקשוקה, סביב הר השקשוקה וביצי, ראש העיר.

## מה יש בתיקייה
| קובץ | מה זה |
|---|---|
| `index.html` | כל האתר: HTML, CSS ו-JavaScript בקובץ אחד |
| `vendor/three.min.js` | ספריית התלת-ממד Three.js גרסה r128 (מצורפת, לא צריך להתקין) |
| `vendor/THREE-LICENSE.txt` | הרישיון של Three.js (MIT) |
| `vercel.json` | הגדרות ל-Vercel (בלי מטמון על index.html, כדי שעדכונים יופיעו מיד) |

אין תלויות להתקנה, אין `npm install` ואין שלב בנייה. הגופנים (Rubik ו-Assistant) נטענים מ-Google Fonts.

## פרסום ב-Vercel
**אפשרות א, בלי קוד:** vercel.com → Add New → Project → גוררים את התיקייה `shakshuka-city`. Framework Preset: **Other**. Build Command: ריק. Output Directory: `.` (התיקייה הראשית).

**אפשרות ב, משורת הפקודה:**
```bash
npm i -g vercel
cd shakshuka-city
vercel --prod
```

## איך האתר עובד
- **מבקרים** (`https://<domain>/`): מסתובבים בעיר (גרירה = סיבוב, צביטה/גלגלת = זום), רואים את כל הבתים, מחפשים תושב ועפים לבית שלו, "מצב צילום" שמסתיר את הכפתורים ומסובב את המצלמה.
- **מנהל**: נכנסים עם `https://<domain>/#admin`, או לוחצים 5 פעמים על הכותרת "שקשוקה סיטי" וכותבים את קוד המנהל `אדם גלעד 2`. מופיעים הכפתורים "הוסף תושב" ו"ניהול" — הוספה, הזזה (▲▼) והסרה של תושבים, מסיבה בעיר (זיקוקים, קונפטי, אלומות אור), ואווירה (יום / שקיעה / לילה).
- הבית בשם **"אדם גלעד 2"** הוא בית ראש העיר: מחבת זהב, כתר ושלט "מנהל העיר".

## יום 2: אצטדיון השקשוקה ובית הספר של ביצי
- **אצטדיון השקשוקה** (מעבר לגשר החלה, משמאל) מכוסה בבד סגול עם שעון ספירה לאחור. שלט ספירה גדול עם נורות עומד מול הכניסה, ושעון נוסף מרחף מעל הבד. כשהזמן מגיע, הבד עף למעלה, מתגלה האצטדיון ומתחילים קונפטי וזיקוקים. מבקרים רואים למעלה כפתור סגול עם הספירה, ולחיצה עליו מעיפה אותם לאצטדיון.
- זמן הפתיחה נמצא ב-`STATIC_SETTINGS.reveal` (ברירת מחדל: 9.11.2026 בשעה 18:00 שעון ישראל, שבוע מהיום). אפשר לשנות אותו ב"ניהול" > "פתיחת האצטדיון" ואז "שמירת האתר".
- "לפתוח עכשיו" ב"ניהול" מפעיל את החשיפה מיד, לבדיקה או לצילום. זה משפיע רק על הדפדפן של המנהל, עד ששומרים זמן פתיחה ומפרסמים.
- **בית הספר של ביצי** (מעבר לגשר, מימין) הוא אתר בנייה: בניין בצורת ביצה בחצי בנייה, פיגומים, מנוף ושלט "בקרוב".

## טיול בעיר
לוח חיצים (▲▼◀▶) בצד שמאל למטה, וגם חצים או WASD במקלדת, מזיזים את המצלמה בעיר. גרירה מסובבת, צביטה או גלגלת עושות זום.

## מעבר לנהר
כביש עם פנסים מחבר את גשר החלה לשני האתרים. ליד האצטדיון יש שער כניסה, קופות, דוכני אוכל, חניון ועציצים, ודגלונים שמתגלים ביום הפתיחה. בבית הספר של ביצי יש גדר, אוטובוס, מערבל בטון, גן שעשועים בבנייה ואפרוחים פועלים.

## איך שומרים בתים חדשים (חשוב)
זה אתר סטטי בלי מסד נתונים. השמות וההגדרות כתובים בתוך `index.html`, בין הסימונים:
```js
const STATIC_RESIDENTS=/*RES*/["אדם גלעד 2"]/*RES*/;
const STATIC_SETTINGS=/*SET*/{"party":false,"title":"","theme":"day"}/*SET*/;
```
אחרי שינויים במצב `#admin` לוחצים **"שמירת האתר (הורדת קובץ)"**. יורד `index.html` מעודכן, מחליפים בו את הקובץ שבתיקייה ומפרסמים מחדש (`vercel --prod`, או גרירה מחדש). אפשר גם לערוך את שתי השורות האלה ידנית.

`#admin` לא מגן על שום דבר: שינויים של מבקר נשארים רק בדפדפן שלו, ורק מי שמפרסם את הקובץ משנה את האתר לכולם.

## הערות למפתח
- כל הקוד בתוך `index.html` (בלוק `<script>` אחד). הסצנה בנויה ב-Three.js r128, עם InstancedMesh לבתים.
- הקוד בודק אם רץ בתוך Claude (`window.claude`). מחוץ ל-Claude הקריאה הזו לא קיימת, ולכן האתר תמיד רץ במצב הסטטי שמתואר כאן. לא צריך לשנות כלום.
- אם רוצים בעתיד הרשמה עצמית של מבקרים, צריך להוסיף מסד נתונים (למשל Firebase או Supabase) ולהחליף את הפונקציה `goStatic()` בקריאה/כתיבה אליו.
